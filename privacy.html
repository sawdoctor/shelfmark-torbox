Shelfmark audiobooks · Privacy and terms

Privacy policy

This policy describes the personal Shelfmark audiobooks installation maintained by sawdoctor.

Google Drive access

The installation uses rclone with Google OAuth authorization granted by the account owner. It accesses file names, directory structure, sizes and other file metadata to locate audiobooks and verify backups. It reads audiobook content for the owner's authorized playback and backup operations. Backup writing, if enabled for a separately authorized remote, is limited by the installation's configuration and the owner's instructions. A read-only remote cannot upload, rename or delete Drive files.

Use and sharing

Google Drive data is used only for these personal library, playback and backup functions. It is not sold, used for advertising or used to train AI models. Authorized family listeners can receive audiobook playback through the owner's server; they do not receive OAuth credentials. Google processes API requests, and the owner's server processes the requested metadata and audio. The installation does not intentionally disclose this data to unrelated third parties.

Storage and retention

OAuth tokens and client credentials are stored privately on the owner's server. Library metadata, listening progress, operational logs and rollback backups are stored there according to the owner's configuration. A Drive playback mount may temporarily cache audio according to its configured cache limits. Original books and backup-vault objects remain under the owner's control; this policy does not authorize their deletion.

Control and revocation

The owner can revoke authorization in Google Account connections, disable the installation, or change its configuration. Revoking authorization stops future authorized access; it does not automatically delete existing books, backups, metadata or progress.

Google API policy

The installation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This website

These static information pages do not collect OAuth credentials, audiobook data or analytics. GitHub Pages, as the hosting provider, may process normal web request information under GitHub's privacy statement.

Contact

Contact the maintainer through the GitHub project. Do not include secrets, tokens or private audiobook information in public reports.
